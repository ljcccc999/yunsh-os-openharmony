# Feature target and release gates

The following is the product target, not a claim that every item is already
released. Each release marks the actual state in its notes.

| Area | Target | Release evidence |
| --- | --- | --- |
| System | Native OpenHarmony image, Pi 5 BSP, boot and drivers | Build log, image checks, Pi 5/QEMU evidence |
| Desktop | YUNSH spatial shell, liquid-glass surfaces, windows | Clean boot and UI test |
| Motion | Bluetooth-connected 3DoF tracking and recenter | Hardware telemetry test |
| Apps | Native HAP installation and launch | HAP install test |
| Connectivity | Wi-Fi, Bluetooth, YUNSH Link and OTA | Device and updater tests |
| Media | Browser, gallery, screenshots, recording and media | Feature-specific test |
| Display | EDID/5K target with safe fallback | Display evidence |
| Excluded | Android/Waydroid | Not shipped |
